# DeepSeek Harness RU

Неофициальный русификатор DeepSeek Harness для Windows x64.

**[Скачать EXE-патчер](https://github.com/afirius/deepseek-harness-ru/releases/latest)** · [Все релизы](https://github.com/afirius/deepseek-harness-ru/releases)

Русификатор проверяет структуру архива приложения и профиля на Windows x64. Реальная
проверка выполнена на DeepSeek Harness **0.1.7-rc.2**. Другие сборки могут пройти
проверку структуры и оказаться совместимыми, но совместимость со всеми будущими
версиями не гарантируется. Новые или изменённые строки интерфейса могут остаться
на английском.

Переводит верхнее меню «Приложение / Правка», его команды, трей, диалоги и экран
приветствия. Веб-плагин содержит 2639 строк в 57 разделах интерфейса. Для новых
или неохваченных строк действует английский fallback.

## Установка

1. Установите официальное приложение DeepSeek Harness и запустите его хотя бы один раз.
2. Полностью закройте его через **Выход**, включая значок в системном трее.
3. Запустите `DeepSeek-Harness-RU.exe`.
4. Проверьте каталог приложения и домашний каталог DSH. Обычно они определяются автоматически.
5. Нажмите **Проверить**, затем **Установить русский**.
6. Запустите DeepSeek Harness. При первом запуске перевод включится автоматически.

После обновления DeepSeek Harness повторите проверку и установку перевода.

Если язык позже был изменён вручную, выберите **Настройки → Основные → Язык → Русский**.
Патчер не меняет последующий ручной выбор языка.

Python, отдельный Node.js и подключение к Интернету для патчера не нужны.
Используется Node.js, который уже включён в установку Harness.
Для обычной установки в `%LOCALAPPDATA%` права администратора не требуются.

EXE не подписан коммерческим сертификатом. Исходный код и локальная сборка доступны
в этом репозитории; SHA-256 готового файла публикуется рядом с ним.

## Откат

Закройте Harness, откройте патчер и нажмите **Удалить перевод**. Исходный заголовок
архива и прежнее подключение плагинов будут восстановлены. Если до установки уже
использовался другой русский плагин, он будет возвращён. Вне активного
архива могут оставаться неиспользуемые файлы перевода; резервные копии сохраняются
в `resources/dsh-ru-patch/backups` внутри каталога приложения.

Переписки, ключи API, модели и остальные пользовательские настройки патчер не
редактирует. При установке меняется только подключение плагина и предпочтение языка.
Резервные копии профиля предназначены для локального восстановления: **не публикуйте
их в GitHub или вместе с EXE**.

## Как это работает

На Windows видимую полосу меню рисует `preload-app.cjs`. У неё собственный словарь,
отдельный от главного процесса и веб-плагина. Поэтому перевод одного `main.js`
не меняет надписи `Application / Edit`.

Патчер читает оригинальный ASAR и проверяет структуру словарей и функций выбора
языка. Переведённые файлы размещаются в `app.asar.unpacked`, а их записи в
заголовке получают флаг `unpacked`. Содержимое исходного payload не изменяется.
Длина заголовка считается в байтах UTF-8 и не выходит за его исходные границы.

Перед заменой выполняется проверка JavaScript штатным Node.js. Записи выполняются
через временные файлы, исходники сохраняются в журналируемую резервную копию.
При обнаруженной ошибке установки изменения откатываются. После аварийного
прерывания незавершённый журнал восстанавливается перед следующей установкой
или удалением. Патчер не завершает
процессы Harness и не прерывает задачи. Повторная установка не накладывает перевод
поверх перевода.

После каждого обновления Harness заново проверьте структуру архива и профиля. Если
проверка проходит, установите перевод ещё раз. Патчер не переносит старый заголовок
на изменённый архив. Другие сборки могут быть совместимы, однако поддержка всех
будущих версий не обещается; новые строки могут остаться на английском.

## Сборка EXE

Нужна Windows с .NET Framework 4.x и его компилятором `csc.exe`:

```powershell
powershell -NoProfile -File .\build.ps1
```

Результат: `dist/DeepSeek-Harness-RU.exe`. Сборка локальная, без NuGet и сетевых загрузок.
В EXE входят только инструменты патчера и словари. Сам Harness не распространяется.

Для тестов установите Node.js 24 либо используйте runtime из Harness:

```powershell
node --test tests/*.test.mjs
```

Интеграционные тесты используют копии установленного архива во временном каталоге.
Путь к приложению задаётся через `DSH_TEST_INSTALL`; при отсутствии переменной
такие тесты пропускаются. Живая установка не изменяется.

## Командная строка

```powershell
.\DeepSeek-Harness-RU.exe --check --install-dir "C:\путь\DeepSeek Harness" --dsh-home "C:\путь\.dsh" --log "check.log"
.\DeepSeek-Harness-RU.exe --install --install-dir "C:\путь\DeepSeek Harness" --dsh-home "C:\путь\.dsh" --log "install.log"
.\DeepSeek-Harness-RU.exe --uninstall --install-dir "C:\путь\DeepSeek Harness" --dsh-home "C:\путь\.dsh" --log "uninstall.log"
```

Код завершения 0 означает успех. Лог обязателен в командном режиме.
`--self-test --log self-test.log` проверяет извлечение встроенных файлов, не изменяя Harness.

## Публикация на GitHub

1. Создайте публичный репозиторий, например `deepseek-harness-ru`.
2. Загрузите содержимое архива исходников: `README.md`, `LICENSE`, `NOTICE`,
   `build.ps1`, каталоги `launcher`, `tools`, `payload`, `tests` и `.gitignore`.
3. Создайте Release `v1.1.0` и приложите `DeepSeek-Harness-RU.exe` и `SHA256SUMS.txt`.
4. В описании релиза укажите, что реальная проверка выполнена на **0.1.7-rc.2 / Windows x64**;
   совместимость других сборок определяется проверкой структуры и не гарантирована для всех будущих версий.

Не загружайте каталоги установленного Harness, `app.asar`, `.dsh`, резервные копии
или личные журналы. Этот проект не является официальным продуктом DeepSeek.
